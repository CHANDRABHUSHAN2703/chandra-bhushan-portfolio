# Chandra Bhushan Pathak — Portfolio

A responsive, recruiter-friendly personal portfolio built with plain HTML, CSS and JavaScript.
It is intentionally company-agnostic and visually inspired by warm neutral editorial design, so it can be used for internships, full-time roles,
freelance work, referrals and general networking.

## Included
- Responsive one-page portfolio
- My profile photo
- Resume PDF
- About, skills, projects, journey and contact sections
- Scroll reveal animations with reduced-motion support
- Mobile navigation
- Dynamic GitHub / LinkedIn / LeetCode buttons
- Vercel / Netlify / GitHub Pages friendly — no build step

## Before publishing
Open `script.js` and replace these values if your actual profile URLs were not recovered
from the resume PDF:

```js
github: "",
linkedin: "",
leetcode: "",
```

Your email and QR-ify live link are already configured.

## Run locally
Just open `index.html` in a browser, or use VS Code Live Server.

## Deploy
Upload the folder to GitHub and import the repository into Vercel, or deploy it to
Netlify / GitHub Pages as a static site.

The portfolio uses semantic HTML, responsive layouts and reduced-motion handling.
The design also avoids unnecessary dependencies to keep the page lightweight.
